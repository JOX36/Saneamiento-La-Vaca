⚙️ Conectar base de datos

Conecta Supabase para guardar todos los registros en la nube y consultarlos desde cualquier dispositivo. Es gratuito.

1. Crea el proyecto en supabase.com y ejecuta este SQL:

CREATE TABLE registros ( id BIGSERIAL PRIMARY KEY, consecutivo TEXT NOT NULL, fecha DATE NOT NULL, programa TEXT NOT NULL, area TEXT, responsable TEXT, turno TEXT, datos JSONB, observaciones TEXT, estado TEXT DEFAULT 'Conforme', created_at TIMESTAMPTZ DEFAULT NOW() ); CREATE INDEX idx_fecha ON registros(fecha DESC); CREATE INDEX idx_programa ON registros(programa); ALTER TABLE registros ENABLE ROW LEVEL SECURITY; CREATE POLICY "pub" ON registros FOR ALL USING (true) WITH CHECK (true);
